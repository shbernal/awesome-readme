# Contributing

## Suggest a README

Open an issue or a PR with:

- the repo link
- what to take from its README, 1 short line per point
- the category it fits in, or a new one

Only list what a README does well. If a README has a habit worth avoiding, add it to the [skill](skills/awesome-readme/SKILL.md) instead.

## Writing style

This repo follows its own advice. Short lines, sentence case headings, no em dashes, no decorative emojis. Run your text through the [unslop skill](https://github.com/cursor/plugins/blob/main/pstack/skills/unslop/SKILL.md) if an agent wrote it.

## AI disclosure

Fully AI-generated issues and PRs are welcome. Say which harness and model you used, for example "Claude Code, Opus 5.5".
